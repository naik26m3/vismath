Four ways to pick a lesson

All four use the same 81 lessons. Try each one on the tablet with a finger, and time how long it takes to reach lesson 6.5.

A. One plain dropdown

The least code: one <select>, one <option> per lesson. The list is 81 rows long, so reaching chapter 6 is a lot of scrolling.

B. One dropdown, grouped by chapter

The same dropdown with an <optgroup> around each chapter. Still one long list, but the chapter headings make it easier to find your place.

C. Two dropdowns: chapter, then lesson

Pick the chapter first; the second dropdown then holds only that chapter's lessons, about nine rows. Two short lists instead of one long one.

D. Chapter buttons, then lesson buttons

No dropdown at all. Everything is visible and each choice is one tap on a big target. Fastest with a finger, but it takes the most room on screen and the most code.

On your page the picked lesson's file would go to loadLesson(...). Here each option just prints what you picked.
